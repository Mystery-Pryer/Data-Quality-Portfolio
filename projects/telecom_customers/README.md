# Telecom Customer Data Quality Investigation

## Project Summary

This project is the planned second case study in the Data Quality Portfolio. It will investigate synthetic telecom customer and account data using SQL and Python/pandas.

## Status

Planned. The current folder contains a project plan and EDA direction only. It should not be treated as a finished portfolio project yet.

## Planned Focus

- Customer record completeness.
- Phone number and email standardization.
- Duplicate customer detection.
- Account/status consistency checks.
- Plan/category conformity checks.
- Relationship checks between customers, accounts, plans, and usage records.
- Stakeholder-ready findings and recommendations.
